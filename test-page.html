Portal Extension Test Page

This page is designed to test the Portal Chrome extension. The extension should automatically capture your visit to this page.

What Should Happen

  • ✓ Page visit is automatically recorded
  • ✓ Page title and URL are captured
  • ✓ Timestamp is recorded
  • ✓ Content is extracted (this text)
  • ✓ Scroll depth is tracked as you scroll
  • ✓ Text highlights are recorded when you select text

Testing Instructions

  1. Stay on this page for at least 10 seconds
  2. Scroll down to the bottom
  3. Highlight some text with your cursor (like this highlighted section)
  4. Click the Portal extension icon
  5. You should see this page in your recent interactions
  6. Search for "Portal Extension Test" - this page should appear

Debug Check

Open your browser console (F12 or Cmd+Opt+I) and check:

  • Portal content script loaded on: ... - Content script is active
  • Any error messages - Problems to investigate

Then check the extension's service worker:

  1. Go to chrome://extensions/
  2. Find Portal extension
  3. Click "Inspect views: service worker"
  4. Look for: ✓ Stored interaction #1: Portal Extension Test Page
