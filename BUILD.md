# Build Instructions

## Quick Start

### 1. Install Dependencies

First, install Rust and wasm-pack:

```bash
# Install Rust (if not already installed)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Install wasm-pack
curl https://rustwasm.github.io/wasm-pack/installer/init.sh -sSf | sh
```

### 2. Build the WASM Module

```bash
# Build for production
wasm-pack build --target web --out-dir extension/pkg

# Or for development (faster builds, larger size)
wasm-pack build --target web --out-dir extension/pkg --dev
```

This will compile the Rust code in `src/lib.rs` to WebAssembly and generate JavaScript bindings in `extension/pkg/`.

### 3. Add Extension Icons

Create or download three PNG icons and place them in `extension/icons/`:
- `icon16.png` (16x16)
- `icon48.png` (48x48)
- `icon128.png` (128x128)

See `extension/icons/README.md` for details.

### 4. Load Extension in Chrome

1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode" (toggle in top right)
3. Click "Load unpacked"
4. Select the `extension` directory from this project
5. The extension should now appear in your toolbar!

## Development Workflow

### Watch Mode

For automatic rebuilds during development:

```bash
# Terminal 1: Watch Rust changes
wasm-pack build --target web --out-dir extension/pkg --dev --watch
```

After making changes:
1. Rust changes: Wait for wasm-pack to rebuild
2. JavaScript/HTML changes: Just reload the extension
3. Reload extension: Go to `chrome://extensions/` and click the refresh icon

### Testing

Test the extension by:
1. Browsing some websites
2. Clicking the extension icon to search
3. Checking the options page for statistics
4. Exporting your data

### Debugging

- **Console logs**: Right-click extension icon → "Inspect popup" or check background service worker
- **Content script**: Open DevTools on any webpage and check console
- **Storage**: `chrome://extensions/` → Extension details → Storage

## Troubleshooting

### WASM module not loading

Make sure:
- `extension/pkg/` directory exists and contains `.wasm` and `.js` files
- You've reloaded the extension after building

### Extension not capturing interactions

Check:
- Content script is injected (look for console logs on webpages)
- Background service worker is running (`chrome://extensions/` → Details → Inspect service worker)
- Permissions are granted (check manifest.json)

### Build errors

Common issues:
- Rust not installed: Install from https://rustup.rs/
- wasm-pack not installed: `cargo install wasm-pack`
- Wrong wasm-pack target: Must use `--target web` not `--target bundler`
