background.js has two responsibilities: convert events to logs, apply logs to cache and offscreen.js. All checkpoints are created explicitly using logs in the first phase. There are two types of page logs: p_visit, p_checkpoint. p_visit updates existing checkpoint, p_checkpoint additionally creates new checkpoint if not exist. Pseudocode:

onVisitEvent(page) {
  logs = []
  if shouldCheckpoint(page) && !cache.has(page) && !fs.exists(page) {
    logs.push(p_checkpoint { .. })
  } else {
    logs.push(p_visit { .. })
  }
  // references
  if page.parent && !cache.has(page.parent) && !fs.exists(page.parent) {
    logs.push(p_checkpoint { page.parent })
  }
  for (key, entity) in effectOf(log, (key) -> { readCacheAndFs(key) }) {
    cache.insert(key, entity)
  }
}
onCapture(page) {
  let log = if !cache.has(page) {
    p_checkpoint { .. }
  } else {
    p_visit { .. }
  }
}

The behavior to update parent's children, is written inside effectOf, and shared by both offscreen.js and background.js. offscreen.js just replay the logs in one pass.
