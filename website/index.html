Find that page you meant to come back to. Browser Recall keeps your browsing history together with the passages you highlight and the notes you write.

Get Browser Recall
Desktop app style

Leave yourself a note.

Highlight a passage on a webpage and leave a note beside it. Save the page to as many lists as you like.

Choose a folder for your library.

Browser Recall saves your history, notes, and snapshots as readable files. You can open those files, back up the folder, or work with your library using your own tools.

Install Browser Recall

Install the desktop app and browser extension on the same computer. Then approve the browser connection in the desktop app.
