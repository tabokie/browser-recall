# Extension Icons

You need to add three icon files in this directory:

- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

These icons represent your extension in:
- The browser toolbar (16px)
- The extensions management page (48px)
- The Chrome Web Store (128px)

You can create simple icons using any image editor, or use online tools like:
- https://www.favicon-generator.org/
- https://realfavicongenerator.net/

For a simple placeholder, you could use a blue circle or square with a "P" (for Portal) in the center.
