# Browser Recall Support

For help with installation, browser pairing, or your library, email
[Browser Recall support](mailto:xy.tao@outlook.com). Include your macOS version,
Browser Recall version, and the browser you use. Keep browsing history, notes,
saved pages, and connection tokens out of support requests.

If Browser Recall asks for access to an existing library, select the same data
folder in the folder picker. To stop automatic capture, open the Browser Recall
toolbar popup and pause recording. The [Privacy Policy](PRIVACY.md) explains how
to revoke browser access and delete stored data.
