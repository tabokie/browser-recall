# Extension Icons

The extension uses the same artwork as the desktop app, resized into Chrome's
required icon sizes:

- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

These icons represent your extension in:
- The browser toolbar (16px)
- The extensions management page (48px)
- The Chrome Web Store (128px)

Regenerate these files from `apps/desktop/src-tauri/icons/icon.png` when the
desktop app icon changes.
