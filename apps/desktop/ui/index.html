browser-recall saves browsing history, notes, and highlights through Browser Recall Desktop into a local plain-text data folder.

Install the browser extension and pair it from the extension popup. Browser Recall Desktop must stay running in the background to record visits.

Launch Browser Recall when you log in

Launch at login is available on macOS 13 or newer.

Choose your data folder

Browser Recall stores plain-text local data in the folder you choose. No default folder is used until you make this choice.

Browsing history Every page visit is automatically saved by Browser Recall Desktop and stays searchable by title, web address, and content.
Highlights & notes Select text and press Alt+H to highlight it, or press Alt+H with no selection to add a note to the current page.
Page snapshots Press Alt+S to save an offline copy of the page through the desktop bridge.
Lists Organize pages into lists. Use automatic inbox rules to create a live-updating list.

Manual setup instructions
  1. Create a private repository on GitHub (e.g. browser-recall-sync). Leave it empty.
  2. Go to Fine-grained tokens and create a token:
    • Set expiration to No expiration
    • Under "Repository access", choose Only select repositories and pick your sync repo
    • Under "Permissions", add Contents and set to Read and write
  3. Paste the repository address and token above.
